## 📚 الخوارزميات المدعومة

### 🏛️ الكلاسيكية
| الخوارزمية | النوع | اللغة |
|---|---|---|
| Binary Encoding | ترميز رقمي | عربي / إنجليزي |
| Caesar Cipher | إزاحة | عربي / إنجليزي |
| Multiplicative | ضربي | عربي / إنجليزي |
| Additive | جمعي | عربي / إنجليزي |
| Columnar Transposition | تبديل | إنجليزي |

### 🚀 الحديثة
| الخوارزمية | النوع | القوة |
|---|---|---|
| P-Box | تبديل بتات | متوسط |
| RSA | غير متماثل | قوي جدًا |
| RC4 | سيلاني | مهجور أمنيًا |
| DES | كتلي | تاريخي |
| **AES-256-GCM** | كتلي | 🛡️ الأقوى عالميًا |
